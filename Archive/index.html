Så fungerar SNURRAN

SNURRAN är en app för dig som inte kan bestämma dig.

🏠 Startsida

Tryck på SNURRA för att slumpa fram ett ställe utifrån dina valda filter så att du vet var du ska gå!



🎯 Filter

Använd Filter för att begränsa urvalet efter typ, pris och stadsdel.


Du kan också välja att endast snurra bland dina favoritställen.



⭐ Favoriter

Hittat ett ställe du gillar? Här kan du söka efter ditt favoritställe och spara det direkt. Du kan också spara ställen som du snurrat fram! Tryck på ❤️ för att spara det som favorit.


Dina senaste favoriter hamnar överst i listan.



🕘 Historik

I Historik hittar du ställen som du tidigare har snurrat fram. Härifrån kan du också spara ställen som favoriter.



❤️ Favoritställen

Vill du bara snurra bland dina favoriter? Aktivera Snurra endast på dina favoriter under Filter.



Nu är det bara att börja snurra!
